# KnoKeep

**Portable, secret-safe memory that lets any AI coding agent resume exactly where the last session — on any tool — left off.**

*Knosky routes to the right file; KnoKeep remembers the work.* Part of the Kno suite. AGPL-3.0.

> Status: pre-release build. This README is a skeleton; the launch version (demo GIF, quickstart, comparison) lands in the growth phase (V6).

## What it does
Flushes your project's exact state (architecture, paths, decisions, active task, next step) to durable, first-party stores that survive context compaction, new threads, and tool switches — Cowork → Cursor → Codex and beyond. Never writes a secret. Self-hostable and airgappable.
